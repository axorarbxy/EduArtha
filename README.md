# EduVaani

> **Understand English. Learn in Your Own Language.**

EduVaani is an AI-powered multilingual educational assistant built using **Google's Gemma 4** to help learners understand English educational content in their native language. Instead of performing literal translations, EduVaani explains concepts in a simple, conversational manner, making learning more accessible for adult and elderly learners across India.

Built for the **Build with Gemma 4 | AI Durg Hackathon** under the **Vaani – Voice First Translation for Bharat** track.

## Project Overview

Many learners struggle to understand educational content because it is primarily available in English. Traditional translation tools often translate sentences word-for-word, making concepts difficult to grasp.

EduVaani solves this by using **Gemma 4** to explain concepts naturally in the learner's preferred language while preserving important technical terms. The application also supports voice interaction, allowing users to speak, listen, and learn in an intuitive way.

# Gemma 4 Integration

EduVaani uses **Google's Gemma 4** through the **Google AI Studio API**.

Every user request follows a structured prompting pipeline where Gemma is instructed to:

- Focus on explaining concepts instead of translating text.
- Simplify educational content.
- Preserve important English technical terms.
- Produce conversational responses suitable for learners.

This approach allows EduVaani to provide explanations that are easier to understand and more educational than traditional translation systems.

# Running the Project

Clone the repository.

```bash
git clone https://github.com/your-username/EduVaani.git
```

Move into the project directory.

```bash
cd EduVaani
```

Install dependencies.

```bash
npm install
```

Start the development server.

```bash
npm run dev
```

The application will run at:

```
http://localhost:3000
```
